{% trans "What this service is" %}

{% blocktrans trimmed with SITE_NAME=SITE_NAME %}{{ SITE_NAME }} is a website where donors register their blood type and area, and where families can see how many compatible donors are ready in their city. It does not store or supply blood. Hospitals and blood banks always make the final decision about who may donate.{% endblocktrans %}

{% blocktrans trimmed with SITE_NAME=SITE_NAME %}{{ SITE_NAME }} is a student project, built for the course CSC-206 Software Engineering at Aror University of Art, Architecture, Design and Heritage, Sukkur.{% endblocktrans %}

{% trans "How matching works" %}

{% trans "A donor is shown as ready, and matched to a request, only when all of these are true:" %}

{% trans "Compatible blood" %}{% trans "The donor's blood group can safely give red blood cells to the patient's group, using the standard chart." %}
{% trans "Available" %}{% trans "The donor has switched availability on." %}
{% trans "Rested" %}{% blocktrans trimmed with cooldown=cooldown %}At least {{ cooldown }} days have passed since the donor's last donation.{% endblocktrans %}
{% trans "Nearby" %}{% trans "The donor is in the same city as the request, and donors in the same area come first." %}
{% trans "Still open" %}{% blocktrans trimmed with Critical=hours.Critical Urgent=hours.Urgent Normal=hours.Normal %}A request stays open for {{ Critical }} hours if Critical, {{ Urgent }} hours if Urgent, and {{ Normal }} hours if Normal, unless it is marked fulfilled sooner.{% endblocktrans %}

{% trans "Privacy notice" %}

{% trans "What we keep." %} {% trans "When you create an account we keep your username, your email address, and a scrambled (hashed and salted) version of your password. We never see or store your password as you typed it. If you register as a donor we also keep your name, mobile number, blood type, area, last donation date, whether you are available, and the two confirmations you gave. When you post a request we keep its details, such as the hospital, the blood type needed, and a contact number." %}

{% trans "Who can see what." %}

{% trans "Anyone" %}{% trans "Only counts, such as how many donors are ready in an area, and open request cards showing the hospital, area, blood type and urgency. Never names, patient names or phone numbers." %}
{% trans "Signed-in people" %}{% trans "Their own profile and requests. A donor's phone number is shared only with the person whose request that donor offered to help with, and only if the donor agreed when registering. A patient's contact number is shown only to the person who posted the request, the hospital it names, and donors who offered to help with it." %}
{% trans "Administrators" %}{% trans "Can view records in the admin panel, for moderation and support." %}

{% trans "Cookies and browser storage." %} {% trans "We use one cookie to keep you signed in and to protect forms from forgery. Your light or dark choice is saved in your own browser. We do not use advertising or tracking cookies, and nothing on these pages is loaded from other websites." %}

{% trans "Safety notice" %}

{% trans "In an emergency, contact the hospital's blood bank directly." %} {% blocktrans trimmed with SITE_NAME=SITE_NAME %}{{ SITE_NAME }} is a helper, not a medical service, and it cannot promise that a donor will respond.{% endblocktrans %}
  • {% trans "Every donor is screened by a hospital or blood bank before donating. Being shown as ready here does not mean a person is medically fit to donate." %}
  • {% trans "The compatibility guide covers red blood cell donations only. Plasma and platelets follow different rules, so always confirm with the hospital." %}
  • {% trans "Donating blood should be voluntary. Be careful with anyone who asks for money, and confirm any request with the hospital before you travel." %}
